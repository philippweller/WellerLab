# WellerLab widgets

`wellerlab` 0.2.8 — everything lives in **one** Orange category, **Weller Lab** (19 widgets). Generated by `tools/gen_widgets_md.py`; do not edit by hand.

Install/update through Orange's *Options → Add-ons* dialog (PyPI package `wellerlab`), or per terminal with Orange's own Python:

```bash
"/Applications/Orange.app/Contents/MacOS/python" -m pip install --no-user --upgrade --no-deps wellerlab
```

## Metabo statistics — feature tables (GC-IMS / GC-MS)

- **Metabo Feature Filter** — Remove features with too many missing values, zero variance, or below a detection threshold.
- **Metabo Feature Table** — Import a Compound Discoverer feature table (2-header semicolon CSV) with groups per sample.
- **Metabo Heatmap** — Top-N biomarker heatmap with Ward row clustering, optional dendrogram, configurable group legend and clickable cells; ranks by Results, or by ANOVA/variance computed from Data when no Results are connected. PNG/SVG export.
- **Metabo Preprocess** — MetaboAnalyst-style preprocessing: sum-normalisation, imputation, log2, and autoscale/pareto scaling.
- **Metabo Univariate Stats** — One-way ANOVA, Welch t-test, or Kruskal-Wallis per feature with Benjamini-Hochberg FDR and log2FC.
- **Metabo Volcano** — Volcano plot (log2 fold change vs. -log10 FDR) for a two-group contrast; click points to see the per-group distribution as a box plot.

## PLS-DA and OPLS-DA

- **OPLS-DA** — Orthogonal Partial Least Squares Discriminant Analysis with an interactive S-Plot (thresholds, colour coding, feature selection) and R2X/R2Y/Q2 validation.
- **PLS-DA** — Partial Least Squares Discriminant Analysis for classification with categorical targets.

## PCA

- **PCA Pro** — Chemometrics PCA with scaling, explained variance on axes and Hotelling T2/Q-residual outlier diagnostics.

## NMR preprocessing

- **NMR Baseline Correction** — Remove baseline drift from NMR spectra using polynomial fitting or asymmetric least squares.
- **NMR Binning (Bucketing)** — Reduce NMR spectral resolution by binning data points into wider buckets.
- **NMR Calibration** — Shift spectra so a reference compound (TSP, DSS, DMSO, Tris, ...) sits at its absolute ppm (Rnmr1D, NMRProcFlow core).
- **NMR Filter (Savitzky-Golay)** — Smooth and/or differentiate NMR spectra using Savitzky-Golay convolution.
- **NMR Normalization** — Scale NMR spectra to a common intensity level (total area, maximum, unit length, or reference region).
- **NMR Peak Finding** — Deconvolution-based 1H-NMR peak detection (Rnmr1D, NMRProcFlow core).
- **NMR Peak Match** — Annotate peak ppm positions against a reference compound database (Rnmr1D, NMRProcFlow core).
- **NMR Raw Import** — Import 1D NMR raw data (Bruker, Varian/Agilent), pick one experiment, process it (window, zero fill, FFT, phase, baseline, referencing - also by dragging a signal) and emit a spectra table for multivariate analysis.
- **NMR Reference & Alignment** — Align NMR spectra by shifting so a reference peak matches a target chemical shift.
- **NMR Region Exclusion** — Remove spectral regions by specifying ppm ranges (solvent suppression, edge noise removal).

## Typical order of use

1. **Metabo Feature Table** — read a Compound Discoverer export (semicolon CSV, sample/group header rows).
2. **Metabo Preprocess** — sum-normalise, log2, impute, autoscale.
3. **Metabo Univariate Stats** — per-feature ANOVA / Welch / Kruskal-Wallis with BH-FDR, log2FC and group means.
4. **Metabo Volcano** / **Metabo Heatmap** — visualise, click or lasso features, hand the selection on as *Selected Data* (e.g. to a Data Table or PCA Pro).
5. **OPLS-DA** — two-class contrast with an interactive S-plot; pick the class pair in the *Compare* box. **PCA Pro** — scores with Hotelling T²/Q outlier diagnostics.

The NMR widgets expect 1D spectra (ppm columns) and, for Peak Finding / Calibration / Peak Match, an R installation with the Rnmr1D package.
